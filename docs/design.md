# 远程访问设置页

面向正在配置本机 DSH 远程入口的使用者。页面的工作是确认 frpc 可运行、连接参数完整、入口可访问；沿用宿主字体与主题。

颜色基准：正文 slate `#243044`、辅助文字 `#64748b`、边界 `#cbd5e1`、操作蓝 `#2563eb`、成功绿 `#15803d`、错误红 `#dc2626`。正文与边界实际由宿主 currentColor 派生，保持明暗主题一致；只有操作和状态使用语义色。

深色主题的成功、错误文字分别采用 `#86efac`、`#fca5a5`，通过宿主 color-scheme 切换，避免深色背景上的小字对比不足。

字体继承 DSH 的系统界面字体。标题 20px/600，分区标题 14px/600，控件 14px，说明 12px/1.6。所有标签左对齐，控件统一 42px 高；长路径允许换行。

```text
远程访问                 连接状态
启用远程访问             开关
──────────────────────────────
frpc 程序
程序路径                 [检测路径]
检测结果 / 下载进度      [自动安装]
──────────────────────────────
服务器
服务器地址               连接端口
Token                    清除选项
──────────────────────────────
访问入口
代理名称                 类型
映射端口                 访问地址
高级设置
[保存并应用]             保存反馈
```

以表单分区表达不同任务，避免同样大小的卡片堆砌。只让程序检测结果成为主要视觉焦点。宽度依据设置内容容器决定双列/单列，不能仅依赖浏览器窗口宽度。帮助文字独立于标签，避免解释文本让同行控件失去基线；不依赖宿主的 label/input 元素选择器。

设计复核：最初按输入类型配成双列，会让路径操作按钮、复选框和辅助文字落在不同高度；改为“程序检查、服务器、入口”三个任务分区，并让复选框使用独立行。无非交互动画，无外部字体下载。
